Table

Tabla de datos reactiva de grado empresarial inspirada en los patrones de AdminT: abarca desde tablas básicas minimalistas sin barra superior hasta DataGrids Pro con celdas de perfil/avatar, barras de progreso KPI, folios monospace, exportación CSV, modo cliente/servidor y Modo Oscuro nativo integrado de fábrica.

1. Tablas Básicas (Esenciales y Minimalistas)

Cuando necesitas mostrar información puntual en un dashboard sin buscadores ni paginadores complejos: Simple Table (sin barra superior, limpia y directa) y Compact Striped Table con folios monospace e indicadores de estatus con punto (badgeStyle: 'dot').

A. Simple Table (Sin barra superior ni paginación · variant="outlined")
B. Compact & Striped Table con Doble Línea e Indicadores Dot

2. Tabla Completa / Pro · Opción A (Configuración Automática por Defecto)

Con cero plantillas HTML adicionales, <vz-table> construye celdas de perfil con foto o iniciales automáticas (type: 'user'), doble línea con subtítulo (subtitleKey), códigos monospace (type: 'code'), barras de progreso KPI (type: 'progress'), badges semánticos, selección masiva, exportación CSV e iconos SVG nativos de acción (view, edit, delete).

3. Opción B · Personalización a la Medida (Slots y Directivas)

Cuando necesitas reemplazar una parte específica por tu propio diseño sin perder el motor de filtrado, búsqueda y paginación: usa *vzFilterControl para inyectar tus propios filtros (ej. segmented chips), *vzCell para maquetar cualquier celda a medida y [vzTableActions] para agregar botones en la cabecera.
