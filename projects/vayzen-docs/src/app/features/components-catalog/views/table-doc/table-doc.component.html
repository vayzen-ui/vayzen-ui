Componentes / Datos Standalone

Table

Tabla de datos configurable: búsqueda, orden múltiple, filtros y paginación que pueden resolverse en el navegador (todo el JSON en memoria) o delegarse al backend. Sin dependencias externas y con theming por variables CSS.

Demostración en Vivo

Tabla reactiva autónoma en acción con ordenamiento, búsqueda, filtros y paginación en el cliente.

Uso básico · todos los datos en un JSON

Es el modo por defecto: la tabla busca (sin acentos ni mayúsculas), ordena, filtra y pagina por sí sola.

Modo servidor · arquitectura limpia y autónoma

Diseñada bajo los más altos estándares de arquitectura en Angular. La lógica de transporte y llamadas HTTP pertenece a un Servicio, mientras que el componente se encarga únicamente de recibir los datos y alimentar la tabla.

Personalización del diseño

Igual que el botón, la tabla se adapta a tu marca solo con variables CSS: globales en :root o por clase en una tabla concreta, sin ::ng-deep ni !important.
