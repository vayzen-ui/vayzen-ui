Button

Componente de botón reactivo para interfaces modernas: soporta 5 familias visuales (solid, soft, outline, ghost, link), 8 tonalidades semánticas, spinners animados SVG sin desfase dimensional, variantes redondeadas pill, proporción cuadrada iconOnly, badges contadores integrados y Modo Oscuro nativo de fábrica.

Selector: <vz-button> 5 Variantes + 8 Colores Modo Oscuro Nativo

1. Familias de Variantes Visuales

Cinco estilos de superficie para definir la jerarquía de las acciones: solid para llamadas principales, soft para acciones secundarias sutiles, outline para contornos nítidos, ghost para barras de herramientas y link para navegación directa.

Solid Soft Pastel Outline Ghost Enlace

2. Paleta Semántica y Modo Soft Pastel

Ocho tonos semánticos corporativos con alto contraste verificado. La variante soft genera fondos translúcidos al 12% con texto saturado, ideal para tarjetas informativas y dashboards ejecutivos.

Primary Success Warning Danger Info Dark
Primary Soft Aprobado Pendiente Rechazado Análisis Neutro

3. Estados, Spinner de Carga y Eventos

El estado [loading]="true" inyecta un spinner SVG animado, deshabilita la interacción por teclado y cursor, y conserva con precisión milimétrica las dimensiones del botón para evitar saltos molestos de layout.

{{ isSimulatingLoad() ? 'Guardando...' : 'Simular Guardado (1.5s)' }} Clics: {{ clickCounter() }}
Deshabilitado Solid Disabled Outline

4. Tamaños Dimensionales y Modificadores de Forma

Tres escalas estándar (sm: 32px, md: 40px, lg: 48px), píldoras completamente redondeadas con pill (border-radius: 9999px) y proporción 1:1 con iconOnly para barras de herramientas.

Pequeño (sm) Estándar (md) Grande (lg)
Pill Redondeado Pill Soft

5. Iconos Integrados y Badges Contador

Soporte directo para iconos SVG sin dependencias externas (plus, check, download, trash, settings, search, etc.) a la izquierda o derecha, así como insignias o píldoras contadoras integradas (badge="12").

Nuevo Registro Exportar CSV Continuar
Bandeja de Entrada Alertas Activas

6. Personalización con Design Tokens (Variables CSS)

Exposición de variables --vz-btn-* para que cualquier desarrollador pueda cambiar radios, alturas, sombras o colores desde un archivo global, una clase CSS o atributo style sin usar ::ng-deep.
