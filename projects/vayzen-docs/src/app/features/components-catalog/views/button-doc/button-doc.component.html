Arquitectura Híbrida

¿Cómo sobrescribir el diseño para adaptarlo a tu marca?

A diferencia de librerías tradicionales que requieren ::ng-deep o !important, Vayzen UI está construida con CSS Custom Properties que atraviesan limpiamente la encapsulación de Angular. Puedes adaptar el diseño de 3 formas distintas:

Método 1: Nivel Global (:root)

Cambiar toda la paleta o bordes de la aplicación

En el archivo styles.scss de tu proyecto consumidor, define las variables en :root. Toda la librería adoptará automáticamente tu nueva identidad visual.

Método 2: Por Clase CSS Específica

Diseñar un botón especial para una sección (ej. Landing Hero)

Crea una clase en tu componente o SCSS definiendo únicamente las variables que quieres cambiar. No necesitas selectores complicados:

Comenzar prueba gratis → Pill Esmeralda

Personalización puntual y rápida

Referencia de Variables CSS

Lista completa de variables CSS Custom Properties disponibles para personalizar <vz-button>:

Variable CSS Descripción Valor por Defecto
--vz-btn-bg Color de fondo principal del botón var(--vz-primary, #0f172a)
--vz-btn-hover-bg Color de fondo al pasar el cursor (hover) var(--vz-primary-hover, #1e293b)
--vz-btn-active-bg Color de fondo al presionar (active) var(--vz-primary-active, #334155)
--vz-btn-color Color del texto e iconos var(--vz-primary-contrast, #ffffff)
--vz-btn-border-color Color del borde del botón transparent (o --vz-border en outline)
--vz-btn-radius Radio del borde (border-radius) var(--vz-radius-md, 0.375rem)
--vz-btn-padding-y Espaciado interno vertical 0.5rem (en tamaño md)
--vz-btn-padding-x Espaciado interno horizontal 1rem (en tamaño md)
--vz-btn-font-size Tamaño de la tipografía 0.875rem (en tamaño md)
