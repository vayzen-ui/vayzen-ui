Combobox

Selector inteligente de grado empresarial inspirado en los patrones visuales de AdminT: combina trigger con icono prefijo, panel flotante a prueba de colisiones en viewport (detección arriba/abajo), buscador integrado insensible a acentos, opción "Todos" y soporte total para formularios reactivos (ControlValueAccessor).

Selector: <vz-combobox> Auto-Flip Viewport Modo Oscuro Nativo

1. Versión Básica (Autocomplete Simple Zero-Boilerplate)

Configuración rápida con arreglo de opciones simple. Incluye búsqueda en vivo, navegación por teclado y sincronización con [(ngModel)] o formControlName sin maquetar plantillas extra.

Valor seleccionado en el modelo: {{ selectedPais() ?? 'null' }}

2. Versión Enterprise Pro (Icono, Doble Línea, Badges y Portal)

Diseñado para dashboards empresariales de alta densidad. Cuenta con icono prefijo integrado, subtítulos descriptivos por opción, badges semánticos con contraste verificado, opción superior "Todos los corporativos", opciones inactivas deshabilitadas y spinner nativo SVG.

ID de Corporativo: {{ selectedEmpresa() ?? 'Sin selección (Todos)' }}

3. Textos Extensos y Truncado Inteligente (Salto de Línea + Ellipsis)

Demostración de resiliencia ante nombres extensos, razones sociales o normativas kilométricas. El menú desplegable abarca toda la información permitiendo saltos de línea naturales (hasta 2 líneas completas tanto en título como en subtítulo), evitando cortes prematuros. Solo cuando el texto sobrepasa el límite máximo se aplican los puntos suspensivos (...), y el texto completo siempre se puede consultar mediante el tooltip nativo title.

Clave seleccionada: {{ selectedNormativa() ?? 'null' }}

4. Selector de Equipo / Colaboradores (Avatar, Iniciales y Estatus Dot)

Patrón visual moderno para asignación de tareas, responsables y menciones de equipo. Soporta de fábrica círculos de avatar con iniciales o fotografía, indicador luminoso de disponibilidad (online, away, busy, offline), subtítulo con el rol del miembro y actualización automática del trigger al seleccionar.

Miembro seleccionado: {{ selectedTeamMember() ?? 'Ninguno (Select team member...)' }}

5. Opción B: Personalización con Slots (Directivas)

Si requieres un diseño 100% a medida para cada fila (avatares con fotos, etiquetas complejas o acciones), puedes proyectar una plantilla usando la directiva vzComboboxOption.

Responsable ID: {{ selectedUsuario() ?? 'Sin asignar' }}

6. VzSelect (Selector Directo Ligero sin Buscador)

Inspirado en los formularios limpios de AdminT. Para listas breves (departamentos, estatus, roles) donde un campo de búsqueda es innecesario.

Categoría seleccionada: {{ selectedCategoria() ?? 'null' }}

7. VzMultiSelect (Chips Interactivos + Contador y Seleccionar Todo)

Permite seleccionar múltiples elementos con chips removibles integrados en el trigger, insignia contadora +X más, botón rápido de "Seleccionar todos" y buscador inteligente.

Habilidades seleccionadas ({{ selectedHabilidades().length }}): {{ selectedHabilidades().join(', ') || 'Ninguna' }}
