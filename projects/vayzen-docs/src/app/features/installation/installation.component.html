Guía de Instalación

Integra Vayzen UI en tu aplicación Angular en cuestión de segundos. Al estar diseñada con componentes 100% Standalone y CSS nativo, no necesitas importar hojas de estilo pesadas ni configurar proveedores globales complejos.

Paquete: vayzen-ui Tree-Shakeable: 100% Tiempo estimado: 2 min

1. Requisitos del Sistema

Asegúrate de contar con un entorno Angular moderno con soporte para Signals y componentes Standalone.

Framework Angular ^19.0 / ^21.0 Soporte nativo de Signals e inputs reactivos
Node.js >= 20.11 LTS Recomendado para compilación esbuild/Vite
Estilos CSS / SCSS Nativo Sin necesidad de Bootstrap ni Tailwind
