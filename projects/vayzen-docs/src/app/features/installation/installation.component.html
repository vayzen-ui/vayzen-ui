Guía de Instalación

Aprende cómo integrar vayzen-ui en tu proyecto Angular.

1. Instalación mediante npm

npm install vayzen-ui

2. Uso en componentes

Importa el componente Standalone que requieras directamente en tu componente Angular:

import { VayzenUi } from 'vayzen-ui';

@Component({
  imports: [VayzenUi],
  ...
})
